# 🏋️‍♂️ Gimnasio TauroGym

**Gimnasio TauroGym** es un sitio web informativo e interactivo desarrollado para un **gimnasio** que ofrece una amplia variedad de servicios, clases y actividades relacionadas con el **fitness** y el **deporte**.  
El proyecto busca brindar a los usuarios una experiencia moderna, accesible y práctica para conocer todos los servicios del gimnasio, así como facilitar el registro, la consulta de precios y la generación de boletas.

---

## 🚀 Tecnologías utilizadas

- 🧱 **HTML5** – Estructura y contenido del sitio web.  
- 🎨 **CSS3** – Diseño visual, maquetación y estilos responsivos.  
- ⚙️ **JavaScript (ES6+)** – Lógica del sitio, interactividad y manejo de datos dinámicos.  
- 🧾 **jsPDF + AutoTable** – Generación de boletas en formato PDF.  
- 🌐 **API REST** – Integración del formulario de registro de usuarios.  

---

## 🧭 Descripción general

El sitio web ofrece información completa sobre el gimnasio, sus servicios, entrenadores y clases.  
Además, incorpora funcionalidades dinámicas que permiten al usuario **registrarse**, **visualizar precios**, **consultar horarios** y **generar boletas en PDF** de forma sencilla.  

El enfoque principal del proyecto es mejorar la **experiencia del usuario** y proporcionar una **plataforma informativa y funcional** para el público interesado en el fitness y la salud.

---

## 📄 Secciones del sitio

### 🏠 Inicio
- Presenta una visión general del gimnasio, su historia, misión y ubicación.  
- Muestra información introductoria para captar la atención del usuario.

### 💪 Servicios
- Detalla los diferentes servicios ofrecidos: **aeróbicos, cardio, boxeo, musculación, yoga**, entre otros.  
- Incluye **recomendaciones** para un rendimiento óptimo y hábitos saludables.

### 🧑‍🏫 Entrenadores
- Presenta los **perfiles, experiencia y especialidades** de los entrenadores del gimnasio.  
- Permite conocer al equipo profesional detrás de las clases y entrenamientos.

### 🖼️ Galería
- Muestra una **galería de imágenes** con las instalaciones, equipos, áreas de entrenamiento y clases en acción.

### 📅 Clases
- Incluye una **lista de clases disponibles**, con horarios, precios y descripciones detalladas.  
- Permite seleccionar clases y **añadirlas al carrito de compras** para llevar un control del total a pagar.  
- Genera una **boleta en formato PDF** mediante la biblioteca **jsPDF + AutoTable**.

### 📝 Registro
- Formulario de registro conectado a una **API** que permite almacenar o validar los datos ingresados por los usuarios.  
- Garantiza una experiencia fluida y sencilla para nuevos clientes.

### 🛒 Carrito de compras
- Permite visualizar los detalles de las clases o servicios seleccionados.  
- Muestra el **total a pagar** y la opción de generar la boleta correspondiente.

### 📞 Contacto
- Formulario de contacto funcional para enviar consultas o mensajes.  
- También dispone de un **enlace directo a canales externos** (como WhatsApp o teléfono) para consultas de precios y métodos de pago.
